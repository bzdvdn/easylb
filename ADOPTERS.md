# Adopters

environments. It is optional, but public adopters help the project and other
users evaluate it.

> Adding your organization is voluntary and does not imply endorsement.

## How to add your organization

Open a pull request that adds one row above with:

- organization or project name;
- Kubernetes distribution/environment;
- easyLB version you started with;
- optional short note (ingress-nginx, Gateway API, keepalived, node IPs, ...).

If you prefer not to be listed, that is completely fine.
