# Roadmap

The canonical roadmap, completed work, planned features, and out-of-scope
items live in
[ROADMAP.md](https://github.com/bzdvdn/easylb/blob/master/ROADMAP.md).

Current focus:

- per-pool L2 advertisement selectors (node/interface);
- e2e for shared VIPs and IPv6 NDP;
- ready-made Prometheus alert rules and a dashboard.

BGP/BFD/ECMP, DSR, and advanced MetalLB traffic engineering remain out of scope
for the “small bare-metal, no BGP” positioning.
